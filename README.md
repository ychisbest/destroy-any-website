# Destroy Any Website（复刻版）

🎮 **在线试玩：https://destroy-any-website.ych8398527.workers.dev**

复刻 Hugo Duprez 的爆款小游戏 **Destroy Any Website**：输入任意网址，操控火柴人在真实网页上跑跳，
用 7 种武器 + 手雷把网页拆个稀烂，被打穿的地方会露出下面的像素风世界。

## 运行

```bash
npm start          # 或 node server.js，需要 Node 18+（推荐 24+）
# 打开 http://localhost:3000
```

没有任何 npm 依赖。若本机通过 `HTTPS_PROXY` 上网，服务端会自动走代理（Node 24+）。

## 玩法 / 操作

| 按键 | 作用 |
|---|---|
| A / D、← / → | 跑 |
| Space / W | 跳；空中再按一次 = 空翻二段跳；按住 = 喷气背包飞行（无燃料限制） |
| S | 下落；按住可穿过平台一路往下掉 |
| 鼠标 | 瞄准；左键射击；右键扔手雷 |
| 1–7 / 滚轮 | 切换武器：手枪、冲锋枪、霰弹枪、火箭筒、轨道炮、火焰喷射器、追踪导弹 |
| Tab | 记分板 / 统计 |
| Esc | 暂停 |

- 网页里每个**单词、图片、按钮、带背景/边框的 div** 都是可站立、可破坏的平台。
- 顶部 **WEBSITE DESTROYED** 进度条显示网页被摧毁的百分比。
- 火焰会让文字燃烧并蔓延；爆炸有击退，自己的爆炸也会伤到自己。
- 3 秒不操作时，左下角会淡入键位提示框，一有操作就自动隐藏。

## 多人模式（最多 6 人）

1. 在地址栏输入网址 → 「Open a room」，房主决定要拆哪个网站；
2. Esc →「Copy invite link」把邀请链接发给朋友，或让对方输入 5 位房间码加入；
3. 死斗模式，先达到设定击杀数（5/10/20/30）者获胜，房主可一键再来一局。

## 美术（32 位像素风格）

- 背景：7 套场景主题（草原、夜林、黄昏沙漠、海岸、秋林、火山、雪原），按页面高度分段、只在第一次被打穿时才生成。
  使用 Bayer 有序抖动渐变、三色调明暗、多层山脉加大气雾化；生成后统一降低饱和度并压暗，不和网页内容抢眼。
- 角色 / 武器 / 特效：画在 2 倍像素的低分辨率缓冲区里，用最近邻放大，保证像素对齐；角色前后分层描边，
  武器是手绘像素精灵，爆炸是逐层收缩的像素圆，火焰和烟雾使用固定色板。
- 弹坑：外圈焦痕加余烬，坑内按左上光源画内壁阴影。
- UI：斜面面板、分段血条、金属渐变标题，都是 32 位时代的菜单风格。

## 实现要点

- `server.js`：零依赖 Node 服务。`/proxy` 抓取目标网页、去掉脚本、注入 `<base>`，让页面能在同源 iframe 中被操作；
  内置极简 WebSocket 实现做房间与消息转发；房间内的网页只抓取一次，保证所有玩家看到同一份 HTML。
- `public/game.js`：把页面文字拆成逐词 `<span>`，收集元素矩形建立空间网格作为单向平台；
  Canvas 覆盖层渲染角色、弹道、粒子，按世界坐标生成程序化像素画，被打穿处按像素“挖洞”显示。
- 联机：每个客户端对自己的角色权威，开火事件带随机种子在各端确定性重放，方块破坏批量同步。

仅支持桌面端（键盘 + 鼠标）。依赖大量 JS 渲染的网站（SPA）去掉脚本后可能内容很少，这和原版一样属于正常现象。
